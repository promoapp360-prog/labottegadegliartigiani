# La Bottega degli Artigiani — landing page

Pagine statiche della landing per ristrutturazioni chiavi in mano a Milano e provincia.

| File | Percorso pubblico |
|---|---|
| `index.html` | `/` |
| `grazie.html` | `/grazie.html` |
| `privacy.html` | `/privacy.html` |

Le immagini (`/images/hero.jpg`, `/images/craftsmanship.jpg`) restano nel progetto che ospita il sito.
Il form invia i lead a `/api/leads` (database) e via email in parallelo.
Configurazione nel blocco `window.SITE` in cima a `index.html` e `grazie.html`.
